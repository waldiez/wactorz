    move

    • move(id: string, how: TargetMove, name?: string): void

      Make the agent id (called name, when the list does not say) the target.

      claim is the person's own choice: picking an agent, sending or speaking to one. It is settled, so nothing moves it under them, and remembered, so it is in the address and is where the next load opens. settle is a move made for them because theirs went away: settled, but not remembered, or the next load would bring it back as though chosen. default fills an empty choice while they have been shown nothing.
