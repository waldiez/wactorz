    reconcileAgents

    • reconcileAgents(liveAgents: AgentInfo[], now?: number): void

      Merge in the server's list of its own agents.

      An agent missing from it is removed only once it has also been silent past STALE_MS. The list is not the whole picture: an agent that is ending itself has left it before its delete frame arrives, and an agent of another server on the same broker is never in it while its heartbeats keep arriving. Removing either on the list alone put the card back on the next heartbeat. Agents on a node are never in the list and are left to pruneSilentRemoteAgents.

      Parameters

      • liveAgents: AgentInfo[]
      • now: number = ...

      Returns void
