    reconcile

    • reconcile(open: ChatMessage[], answered: ChatMessage[]): Reconciled

      Bring the questions in line with the server's ledger: add the open ones not held yet, mark those answered meanwhile, and remove an open question the ledger no longer lists.

      Only for the agents the ledger knows — those with a question open or answered in it. An agent that keeps no book of questions asks only live, and its questions are left as they are.

    reset

    • reset(agent: string | null, agentId?: string | null): void

      Drop the threads of the agents called agent — their own messages and everything said to them — or every thread when agent is null. By name, as the server resets them: every agent that went by it. agentId limits it to that agent's thread, where another shares the name. Every thread's history is to be fetched again either way: the server's copy may have been reset with it.

      Parameters

      • agent: string | null
      • agentId: string | null = null
